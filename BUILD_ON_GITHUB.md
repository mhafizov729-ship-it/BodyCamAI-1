# BodyCam AI — сборка APK через GitHub Actions

1. Загрузите этот проект в репозиторий GitHub.
2. Откройте **Actions → Build BodyCam AI APK**.
3. Нажмите **Run workflow**.
4. После завершения откройте результат запуска и скачайте artifact **BodyCamAI-debug**.

Workflow сам устанавливает JDK 17, Gradle 9.2 и Android SDK API 35.
